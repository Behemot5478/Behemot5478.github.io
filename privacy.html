Privacy Policy

Effective Date: September 8, 2026

App Name: TikTok Bot Studio

1. Overview

TikTok Bot Studio is a personal creator productivity desktop/web application that allows content creators to generate short-form videos and publish them directly to their own TikTok accounts using TikTok's official Content Posting API.

2. Data Collection & Usage

Our application collects only the necessary OAuth tokens required to authenticate with TikTok APIs on behalf of the authorized user. We do not store, sell, share, or transmit user personal data to any external third party.

  • OAuth Tokens: Stored locally on the user's local machine solely to authenticate API requests to TikTok.
  • Video & Audio Files: Stored locally on the user's local storage drive (H:\).
  • User Profile Info: Used solely to display the connected creator nickname/username inside the local user interface.

3. TikTok API Scopes & Access

The application requests access to:

  • user.info.basic: To verify account connection status and creator username.
  • video.publish: To publish creator videos with titles and hashtags to TikTok.
  • video.upload: To upload video files to TikTok servers upon user request.

4. Data Retention and Deletion

Users have complete control over their local data and can delete generated videos or revoke TikTok authorization tokens at any time directly through the application interface or their TikTok account settings.

5. Contact Us

If you have any questions regarding this Privacy Policy, please contact the developer at support@tiktokbotstudio.local.
